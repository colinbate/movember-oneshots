# Colin's Movember Charity Games

This is the public face of my annual TTRPG charity games that I run to raise money for men's health.

Contact me if you are interested in playing.

## Environment

The 2026 page loads its live schedule from Chronos in the browser. Set
`PUBLIC_CHRONOS_API_URL` to the full public event API endpoint before building.
The endpoint must allow browser requests from the site's origin.
